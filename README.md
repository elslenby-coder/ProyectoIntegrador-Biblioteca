# Proyecto Integrador - Biblioteca en Línea

Este proyecto implementa un sistema de biblioteca en línea con arquitectura en capas:

- **Presentación**: Interfaces gráficas y vistas.
- **Aplicación**: Casos de uso y lógica de aplicación.
- **Dominio**: Entidades y reglas de negocio.
- **Infraestructura**: Persistencia de datos y servicios externos.

## Evidencia
- Repositorio clonado y configurado en GitHub.
- Arquitectura creada y documentada.
- Cambios confirmados y subidos con Git.
